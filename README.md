# hermes-sofi-experiment-plugin

Desktop half of the SoFi Experiment board plugin (guided book vs bot rules
A/B scoreboard for x-investing-bot). Backend (`plugin_api.py`) lives on
ai-agent at ~/.hermes/plugins/sofi-experiment and is already enabled.

Install on the machine running the Hermes desktop app:
Settings -> Plugins -> Install from Git -> this repo -> tick Desktop.
Or copy `desktop/plugin.js` to `~/.hermes/desktop-plugins/sofi-experiment/plugin.js`
and run "Reload desktop plugins" from the command palette.
